GitHub Pages 跑通了

这是一个最小可运行的静态站点：纯 HTML + 内联样式，零依赖、零构建。 能看到这一页，说明仓库、分支和 Pages 设置都已经正确。

下一步可以做什么

  1. 把 index.html 的内容换成你真正想放的页面。
  2. 需要多页就在同目录新建 about.html，用相对链接互跳。
  3. 要自定义域名，在仓库 Settings → Pages 里填域名并配置 DNS 记录。
  4. 每次 git push 后，Pages 会自动重新发布，通常 30 秒内生效。

本地预览

直接双击打开这个文件即可；或用任意静态服务器：

python -m http.server 8000
# 然后访问 http://localhost:8000

## 「十优缠论」静态内容站 设计（11-18 续）

用户需求：缠论知识分享 + 收盘复盘/消息解读日更 + 引导进微信社群，后期可加广告。

**已冻结的决策（后续改动需重新评估，勿轻易推翻）**
- 品牌名：**十优缠论**（非"拾优"）
- 栏目 3 个：`learn` 缠论知识 / `review` 收盘复盘 / `news` 消息解读
  - **`stock` 个股栏目已取消**（用户无投顾资质），个股内容并入 review 正文倒数第二节「个股结构拆解」
- 导航 4 项：缠论知识 · 每日复盘 · 消息解读 · 社群（「关于」并入 `/community/`，归档降页脚）
- 技术栈：**Astro 5 + Node 22 + content collections(zod) + GitHub Actions + Pages**
  - 否决 VitePress（文档站骨架，不适合内容流）、Hexo（主题即 EJS，技术债）、Eleventy（缺 frontmatter 校验）、纯手写 HTML
- URL 契约：`/chan003/<section>/<YYYY-MM-DD>/`（review/news）、`/chan003/learn/<slug>/`；文件名=slug=URL段；不带栏目前缀、不带年月层级
- CTA：全站只用**公众号二维码**（长期有效）；群活码只在 `/community/`；进群路径=关注→回复「入群」→自动回群码；超 7 天构建期自动隐藏群码
- 图片规范：首图 ≤1200px/≤100KB 不懒加载 high priority；正文图 ≤1600px/≤150KB lazy；300KB 是红线非目标
- 视觉 token：深色头部 `--ink-950 #0B141F`，浅色暖白底 `--paper #F5F4F1`，品牌朱砂红 `--brand #A82C2C`，链接蓝 `--navy #1D4E7C`，**涨红 `#C7382F` / 跌绿 `#1B7F58`**
- 文案硬禁令：站内不承诺推送具体时点（只承诺"每个交易日"）；禁用"买入/卖出/目标价/稳赚/带你赚/跟上操作"；不承诺"预计 16:30 送达"
- 时效分工：公众号承诺 16:30 推送，站点不重复承诺

**关键洞察（值得复用）**
- 本站不是流量生意是信任生意 → 零 JS、不做弹窗、不做强制留资、放弃跟单型流量，全部由此推导
- 校验设计四原则：不制造可低成本绕过的检查、不提示不该做的动作、不在运行时做能放到构建期的事、删掉的自动校验必须有低频人工兜底
- `github.io` 对国内股民不可作唯一入口 → P0 绑域名+Cloudflare / P1 双出口 / P2 国内托管，迁移成本低的根因是 dist 与托管解耦
